## Workflow

1. **Reference Analysis**: Analyze any user-provided references or design constraints.
2. **Design System**: Define specific, premium typography pairings, color palettes (HSL/HEX), and core UI components.
3. **Motion Language**: Determine the animation feel (e.g., snappy anime, smooth corporate, or cinematic).
4. **Artifact Creation**: Produce a visual direction artifact. Do NOT write production code during this step.
