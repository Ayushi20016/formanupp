## Workflow

1. **Environment Audit**: Inspect `package.json`, config files, and the current tech stack.
2. **Architecture Mapping**: Map out the routing, state management, and asset directories.
3. **Protected Sections**: Identify protected assets or sections based on workspace `AGENTS.md` or global rules.
4. **Report**: Generate a detailed audit artifact containing findings and constraints before any work begins.
