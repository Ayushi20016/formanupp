## Workflow

1. **Planning Phase**: Formulate a targeted implementation plan. **Do not modify production projects without first producing a plan.**
2. **Tool Selection**: Choose only the absolutely necessary VFX systems (e.g., PixiJS vs Three.js vs pure DOM).
3. **Implementation**: Integrate `anime-motion-principles` alongside specific VFX skills (`energy-slash-and-trail-effects`, `anime-impact-frame-system`).
4. **QA**: Call `/visual-qa` upon completion.
