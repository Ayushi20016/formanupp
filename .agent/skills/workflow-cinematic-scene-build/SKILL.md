## Workflow

1. **Prerequisite Check**: If no visual direction exists, call `/visual-direction` first.
2. **Planning Phase**: Formulate an implementation plan utilizing skills like `cinematic-web-typography` and `gsap-motion-direction`. **Do not modify production projects without first producing a plan.**
3. **Approval**: Stop and await user approval on the plan.
4. **Execution**: Build the fixed-viewport scene using rigorous React cleanup patterns.
5. **QA**: Call `/visual-qa` upon completion.
